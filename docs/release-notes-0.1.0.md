第一个公开版本，测试版。

装之前提醒：这是 0.x 的测试版，界面与提示词还会改，升级可能调整设置项与 CSV 口径。建议先备份 Zotero 数据目录里的 `english-assistant/wordbook.json` 和 `prefs.js`。

## 能做什么

- **划词翻译**：在 PDF / EPUB 里选中词、短语、句子、段落，交给大模型翻译。结合选区前后的原文与文献元数据判断语境义，给出「通用释义 + 它在这句话里的意思」。四档解释语言：简体中文、简体中文·精简、简单英文（母语幼儿模式）、简单英文·极简。
- **整本词频**：统计整篇文献的词频，CSV 写在文献同目录，区块里可直接翻页看词表；非英文会拒绝并给出判定依据。
- **分部词频**：只统计 PDF 的指定页区间，单独出 CSV，可回看历史。
- **单词本**：收藏自动补音标与按词性的释义，独立窗口卡片浏览，支持移除单个词与「移除一整页」。
- **配置备份**：全部设置导出成一个 JSON，换机器时一键导回。

## 支持的模型服务

DeepSeek、OpenAI、Kimi、智谱 GLM、通义千问、硅基流动、OpenRouter、Groq、Ollama、LM Studio、Anthropic Claude、Google Gemini，以及任意「OpenAI 兼容」的自定义地址。

## 安装

1. 下载下面的 `english-assistant.xpi`。
2. Zotero →「工具 → 插件」→ 右上角齿轮 →「Install Plugin From File…」，选中它。
3. 重启 Zotero。
4. 「编辑 → 设置 → 英文助手」→「AI 服务」：选服务商、填 API Key、点「读取模型」。

支持 Zotero 7 及以上（开发与实测环境 Zotero 10.0.6）。

## 已知限制

- 扫描版 PDF 没有文字层时要先 OCR。
- EPUB 支持整本词频与翻译，但不支持分部统计。
- 翻译历史只在内存里，重启后清空。
- 词源与例句由模型生成，可能有误。
- 词频不合并比较级（`bigger` 不会并进 `big`）。

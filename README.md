# 英文助手（Zotero 插件）

适用于 Zotero 的英文阅读助手插件，功能包含：**划词翻译**、**整本 / 分部词频统计**、**单词本**，都在右侧栏里，共用同一套设置。

![版本](https://img.shields.io/badge/版本-0.1.0--beta.1-orange)
![Zotero](https://img.shields.io/badge/Zotero-7.0%20~%2010.x-blue)
![许可](https://img.shields.io/badge/许可-MIT-green)

> **这是测试版（Beta 1）。** 主体功能可用，细节还在改：界面文案、提示词、统计口径都可能随版本变动。装之前请先备份 Zotero 数据目录里的 `english-assistant/wordbook.json` 和 Zotero 自己的 `prefs.js`。

## 这个插件做什么

- **划词翻译**：在 PDF 或 EPUB 里选中词、短语、句子、段落，交给任意一家带 API 的大模型服务翻译。插件会把选中位置前后的原文、文献的标题作者年份摘要一起送过去，所以单词和短语给的是「它在这句话里的意思」，不是词典里的一串义项。
- **整本词频**：统计一篇英文文献的整本词频，结果写成 CSV 放在文献同目录，区块里同时显示可翻页的词表。识别到非英文会拒绝统计并给出判定依据。
- **分部词频**：只统计 PDF 的某几页，单独出一份 CSV，不覆盖整本结果。
- **单词本**：值得记的词和短语收进插件自带的单词本，从「工具 → 单词本…」打开，卡片式浏览。

与常见翻译工具的区别在上下文：同一个词在这篇文献里出现很多次，插件取的是**你选中的那一处**前后文，不是全文第一次出现的位置。

- 支持 Zotero 7 及以上，开发与实测环境是 Zotero 10.0.6（Gecko 140）
- 界面中文，代码与文档也是中文；`locale/en-US` 里有英文文案

## 功能一览

| 功能 | 在哪 | 说明 |
|---|---|---|
| 划词翻译 | 阅读器选区 → 「AI 翻译」 | 四档解释语言：简体中文、简体中文·精简、简单英文、简单英文·极简 |
| 整本词频 | 右侧「整本词频」区块 | 输出 CSV，带元信息，可复现 |
| 分部词频 | 右侧「分部词频」区块 | 只 PDF；PDF 要先在阅读器里打开 |
| 单词本 | 工具 → 单词本… | 收藏自动补音标与按词性的释义 |
| 配置备份 | 设置 → 配置备份 | 全部首选项导出成一个 JSON |
| 区块开关 | 设置 → 右侧区块 | 三个区块可以分别隐藏 |

## 安装

**从 Releases 装（推荐）**

1. 到 [Releases](../../releases) 下载最新一版的 `english-assistant.xpi`。
2. Zotero 里「工具 → 插件」，右上角齿轮 → 「Install Plugin From File…」，选中刚下载的 `.xpi`。
3. 重启 Zotero。
4. 打开「编辑 → 设置 → 英文助手」，在「AI 服务」里选服务商、填 API Key、读取模型。

**从源码装**

```powershell
npm run release      # 打包到 dist/english-assistant.xpi，并在文件管理器里选中它
```

然后在 Zotero 里同样用齿轮 → 「Install Plugin From File…」选中 `dist/english-assistant.xpi`。

## 支持的文件格式

- **PDF**：划词翻译、整本词频、分部词频都能用。
- **EPUB**：划词翻译、整本词频能用；分部词频暂不支持（没有稳定的页码）。

EPUB 的词频读的是 Zotero 自己的全文缓存，第一次用某本书之前要等 Zotero 建好索引（条目上右键「重建全文索引」可以手动触发）。没索引时插件会提示，不会抛英文异常。

翻译的上下文窗口：PDF 前后各约 1200 字符，EPUB 约 2000 字符并优先对齐到段落边界。

## 用法：划词翻译

1. 打开 PDF，选中要查的内容。
2. 划词弹窗里点「AI 翻译」。
3. 结果显示在右侧「AI 翻译」区块，按文献归档，历次结果都能回看、复制、删除。

区块上的两个按钮：齿轮打开设置，垃圾桶清空当前文献的历史记录。

**词条右侧的数字来自该文献的词频表**（整本词频那份 CSV）。表里没有这个词就不显示——这篇文献还没跑过词频，或者这个词只出现一次被「忽略只出现一次的词」过滤掉了。短语没有数字，词频表是按词统计的。

**四档解释语言**

| 档位 | 卡片内容 |
|---|---|
| 简体中文 | 音标、通用释义（按词性）、在本句中的含义、原句与译文、例句、讲解、词源 |
| 简体中文·精简 | 只给通用释义和在本句中的含义，回复更快 |
| 简单英文 | 两三段简单英文，像给母语幼儿解释；会话式说明 |
| 简单英文·极简 | 同上但更短，通常只给一句话 |

简单英文两档允许一点点排版（`**加粗**`、`==变色==`、一两个表情），别的花样不渲染。这两档不看目标语言。

## 用法：单词本

三个地方都能收藏，用的是同一份数据：

- **翻译卡片**：单词和短语右上角有「收藏」，已在单词本里时变成「移除收藏」（会先确认）。
- **词频表**：每行末尾的星标，`☆` 未收藏、`★` 已收藏，点一下切换。
- **同一个词重复收藏**只记「又见一次」，不重复占位。

第一次收藏时会自动补音标和词典释义：把这个单词本身发给模型，像词典一样按词性整理常用含义，存进单词本。所以从词频表收藏的词也有音标和释义。

「工具 → 单词本…」打开独立窗口：每页 9 张卡片，3×3 排布，卡片尺寸跟着窗口走（保持同一宽高比），窗口最小 520×420；「上一页 / 下一页」固定在底部；右上角「移除一整页」一次移出当前页（会先确认）；卡片右上角的 ✕ 移出单个词。

数据在 Zotero 数据目录的 `english-assistant/wordbook.json`，纯文本，可以直接备份；文件写坏时插件会先改名留档再重建。

## 用法：整本词频

1. 选中一条带 PDF（或 EPUB）的文献。
2. 右侧「整本词频」区块点「统计词频」。
3. 结果写成 CSV 放在文献同目录（`storage/<附件 key>/`），区块里同时显示可翻页的词表。

- 判定为非英文的文献会被拒绝，并给出可核查的依据（英语功能词命中率、次高语言是哪门、领先多少倍）。设置里可以关掉这个门槛。
- 词形默认归并：`dogs → dog`、`am/is/are → be`、`walked/walking → walk`；只并屈折变化，不并派生（`happiness` 不会并进 `happy`）。
- 自带一份默认自定义名单（约三百个最简单的词），第一次用就已经填好；设置里可以加词、移除、导入导出、恢复默认。这个隐藏只影响区块显示，CSV 里那些词还在。
- 统计方式（停用词、最短词长、忽略只出现一次的词、前 N 个）会同时影响 CSV，元信息会写明这次用了哪些过滤，结果可复现。
- 文献已经统计过时，区块自动读回 CSV 显示，按钮变成「更新词频」。

## 用法：分部词频

1. PDF 要先在阅读器里打开（分部统计从阅读器的 PDF.js 视图逐页取正文）。
2. 右侧「分部词频」区块填起始页和结束页，输入框上右键有「填写当前页码」。
3. 区块里的词表带分页、隐藏自定义单词、单词本星标，行为和整本词频一样。

- CSV 文件名带范围和统计时间：`<PDF 名>_wordfreq_pages_12-34_20261017-173005.csv`。每次统计都生成新文件，不覆盖旧结果。
- 「查询分部」把这篇文献之前的分部结果按时间倒序列出来，可以打开或删除（只删 CSV，不动附件）。
- EPUB 暂时不支持分部统计，选中 EPUB 时区块会说明，请用「整本词频」。

## 用法：配置备份

设置面板最下面的「配置备份」一组：

- **导出所有配置…**：把本插件的全部首选项写成 JSON（默认名 `english-assistant-config-20261031-183000.json`），含接口地址、模型、解释语言、上下文开关、词频统计方式、自定义名单。
- **导入所有配置…**：选一个之前导出的文件，确认后逐项写回；文件里没有的项保持不动，不认识的键跳过。

两件要注意的事：

- **文件里有 API Key**，发给别人前先把 `translate.apiKey` 那一行删掉。
- **单词本不在里面**，它在 Zotero 数据目录的 `wordbook.json`，要备份就单独复制。

## 设置：AI 服务

只有三件必填的事：选服务商、填 API Key、选模型。

- **服务商预设**：DeepSeek、OpenAI、月之暗面 Kimi、智谱 GLM、通义千问、硅基流动、OpenRouter、Groq、Ollama、LM Studio、Anthropic Claude、Google Gemini，外加「自定义」。选中后服务地址自动填成该家默认值（可以改，填中转地址也行）。
- **三套协议**：OpenAI 兼容（`/chat/completions`）、Anthropic（`/v1/messages`）、Google Gemini（`/v1beta/…:generateContent`）。预设自带协议，只有「自定义」需要手选。
- **读取模型**：点「读取模型」去服务商的 `/models` 拉列表（8 秒超时），填进下拉框并自动选中；读不到会在「模型名」框里手填，两条路效果一样。
- **本机服务**（Ollama、LM Studio）不填 Key 也能用。
- **测试连接**用当前界面上的值发一句很短的话，不必先保存。

加一家「OpenAI 兼容」的服务只要在 `addon/chrome/content/scripts/translate/protocols.js` 的 `PRESETS` 里加一行。

## 翻译是怎么工作的

**选类型。** 提示词里有三套输出模板，模型自己判断用哪套：`word`（音标、通用释义、语境义、原句与译文、例句、讲解、词源）、`phrase`（类型、通用释义、语境义、原句与译文、用法、例句、讲解、词源）、`sentence` / `paragraph`（只有译文）。返回结构化 JSON，界面按字段渲染。

**通用与语境在同一个请求里出。** 输出顺序定成先通用释义、后语境义，模型顺序生成，前面那段不会被后面污染。语境义分两行：带词性的简短释义（`inContext.gloss`），加一句「文中指……」（`inContext.note`）。

**高亮在本地定位。** 模型还会给出「译文里与选中部分直接对应的最短中文片段」（`inContext.targetTerm`）。原文用你选中的文字匹配，译文用 targetTerm 匹配，忽略大小写、空白与标点差异；模型圈得偏大时再用 `gloss` 里的中文片段收窄一次。定位不到就不高亮——宁可没有，也不标错位置。

**取上下文。** 主路径从阅读器 DOM 里取选区前后的原文：用选区的 Range 找到所在页，取「页首到选区起点」与「选区终点到页尾」两段，再裁到句子边界；选区贴着页首或页尾时从相邻页补一段。这条路锚定的是你实际选中的那一处，同一个词出现多少次都不会错位。拿不到 DOM 选区时退回「按文字在全文里查找」，这条路只能命中第一次出现的位置，所以只做退路。

**用文献信息。** 附件向上找父条目，取标题、作者、年份、出版物、文献类型、关键词和摘要（截断到 900 字符）。

**出错时。** 常见状态码翻成中文（401 Key 无效、402 余额不足、403 没权限、404 地址不对、429 请求过频或额度用完、5xx 服务端出错），后面接服务给出的说明。失败记录留在历史里，带「重试」按钮。

**推理型模型的空回复。** 有些模型会先把额度花在思考上、正文为空。插件遇到这种情况会把输出上限翻倍重试一次，仍为空才报错，并在提示里说明「思考写了多少字」。

## 词频是怎么工作的

**取正文。** 优先读 Zotero 已建好的全文缓存 `.zotero-ft-cache`；发现它只覆盖了部分页（Zotero 默认只索引前 100 页）就改用 `Zotero.PDFWorker.getFullText(id, null)` 现场提取。取到多少页、走的哪条路，都写进 CSV 元信息。

**判定语言。** 三层：非拉丁字母占比 → 英语功能词命中率 → 与次高语言的领先倍数。样本少于 300 词时不做判定，标「文本太短」。依据和数值写进 CSV。

**切词与归并。** 清洗阶段处理 PDF 常见的行末断词、连字符复合词和大小写；归并阶段用不规则表加后缀规则，并用「本文档出现过的全部词形」裁决歧义，专有名词靠「基本只以大写出现」躲开规则剥后缀。

**输出。** UTF-8 带 BOM、CRLF，前几行是 `#` 开头的中文元信息（来源、生成时间、全文词次、去重词数、归并情况、语言判定、取文本方式），之后是表头 `rank,word,count,share_percent,forms`。

## 隐私与数据

- 插件只把你**选中的文字、选区附近的原文、文献元数据**发给你在设置里指定的服务商；没有其它网络请求，也不收集任何遥测。
- API Key 明文存在 Zotero 自己的 `prefs.js` 里，和其他 Zotero 设置一样；共用电脑时留意。导出配置文件时会把 Key 一起导出。
- Gemini 的 Key 只能放在查询串里（这套协议如此），会出现在服务端与中间代理的访问日志里；走中转服务时留意。
- 单词本、词频 CSV 都写在本地，不上传。

## 已知限制

- **测试版**：界面与提示词还在调整，升级可能改动设置项与 CSV 口径。
- **扫描版 PDF 没有文字层时取不到上下文**：翻译会照常进行并标明上下文不可用，词频会因文本太短而拒绝。需要先 OCR。
- **语境定位可能失败**：PDF 文字层与选区不一致时（罕见字符、连字、断词），插件会说明定位失败，不假装成功。
- **词次只从该文献的词频表里读**：没跑过词频、只出现一次被过滤、或选中的是短语时，不显示数字。
- **翻译历史在内存里**：重启 Zotero 后清空。
- **只处理阅读器里的划词**：注释、条目字段、网页快照的翻译没做。
- **词源和例句由模型生成**，可能有误，别当权威依据。
- **词频不合并比较级**：`bigger`、`happier` 不会并进 `big`、`happy`；学术文本里 `-er` 多是施事名词（`computer`、`reader`），按规则剥会剥出 `comput`。
- **词频偶尔丢连字符**：`machine-generated` 有时被提取成 `machinegenerated`，当成没见过的词。数量很少，没有特殊处理。
- **EPUB 分部统计未做**：分页与字符位置对不上，试过几种办法都不准，先停用。
- 少数服务商的 `/models` 需要额外权限（如 Azure OpenAI 用的是部署名）。读不到就手填模型名，翻译不受影响。

## 开发

```powershell
npm run check     # 静态检查：语法、文案、设置绑定、XML 良构、资源引用、清单字段
npm run selftest  # 两套离线自测：翻译 232 项 + 词频 300 项，都不需要 Zotero
npm run smoke     # 离线冒烟：按 bootstrap 顺序整体加载，跑启动与收尾，32 项
npm run verify    # 上面三件事一起做，提交前跑这个
npm run build     # 打包到 dist/
npm run release   # 打包并在文件管理器里选中 .xpi
npm run demo      # 拿 testdata 里的真实语料跑词频端到端
npm run lemma-audit  # 摊开词形归并结果供人工审查
npm run icons     # 重新生成 PNG 图标（需要 Pillow）
```

改完源码要重启 Zotero 才生效。调试信息在「帮助 → 调试输出」里，搜 `英文助手`。也可以在「工具 → 开发者 → 运行 JavaScript」里直接调：

```js
await Zotero.EnglishAssistant.translate.context.buildContext(
  await Zotero.Items.getAsync(Zotero.getActiveZoteroPane().getSelectedItems()[0].id),
  '要查的短语'
);

Zotero.EnglishAssistant.wordfreq.diagnose();   // 逐个探测用到的宿主接口
Zotero.EnglishAssistant.wordfreq.debugUI();    // 区块注册情况、各窗口 DOM
```

设置项存在 `prefs.js` 里（44 项，界面只暴露常用的一部分），加勾选项要同时改 `addon/prefs.js` 与设置面板，否则 `npm run check` 会报「设置项未接线」。

## 目录结构

```
addon/                          插件本体，打包时整个目录压成 .xpi
  manifest.json                 插件声明，Zotero 从这里读 ID 与版本
  bootstrap.js                  引导脚本：注册 chrome:// 资源、按序加载 26 个模块
  prefs.js                      默认设置（44 项）
  chrome/content/
    preferences.xhtml           设置面板（翻译 + 词频 + 配置备份一个入口）
    wordbook.xhtml              单词本窗口
    scripts/
      main.js                   总入口 EnglishAssistant，编排两个子系统
      translate/                翻译的 12 个模块（config、protocols、api、context、
                                prompts、render、counts、wordbook、panel、service、
                                reader、main）
      wordfreq/                 词频的 13 个模块（langdata、defaults、userlist、lemma、
                                langdetect、tokenizer、wordfreq、output、source、pane、
                                parts-pane、backup、main）
    styles/                     区块、单词本、设置面板的样式
    icons/                     区块图标（Lucide，见 icons/LICENSE-lucide.txt）与 PNG 图标
  locale/{zh-CN,en-US}/english-assistant.ftl   界面文案，id 都带 ea- 前缀
scripts/                        开发脚本（打包、检查、自测、冒烟、图标生成），不进插件
testdata/                       词频自测用的真实语料
docs/                           接口核对笔记、提示词基线、开发过程记录
dist/                           打包产物（不进版本控制）
```
